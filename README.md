Olá, Programa!

Descrição

Este é um programa simples escrito em Python que pergunta o nome do usuário e exibe uma mensagem de saudação personalizada.

Ele é útil para iniciantes que desejam conhecer os conceitos básicos de entrada e saída de dados em Python.

Instalação e pré-requisitos

É necessário ter acesso à internet para usar o OnlineGDB ou ter o Python 3 instalado no computador.

Para executar online:

Acesse o OnlineGDB.

Selecione Python como linguagem.

Cole o código-fonte do arquivo main.py no editor.

Clique em Run.

Não são necessárias bibliotecas externas.

Como usar

Execute o programa e digite seu nome quando solicitado.

Exemplo de entrada:

Beatriz

Resultado esperado:

Qual é o seu nome? Beatriz
Olá, Beatriz!
